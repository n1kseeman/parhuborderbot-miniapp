# PAR HUB Telegram Mini App

Telegram Mini App-клиент PAR HUB: каталог, категории, поиск, фильтры, избранное, корзина, оформление заказа и админ-панель. Данные прототипа хранятся в `localStorage`.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## Что уже работает

- адаптивный мобильный интерфейс и проверка 18+;
- каталог моделей и выбор вкуса, цвета или сопротивления внутри карточки товара;
- категории, поиск, цена, наличие и сортировка;
- избранное, корзина и оформление заказа;
- скрытая админка со статусами заказов и редактированием ассортимента (пять быстрых нажатий на аватар в профиле);
- официальный Telegram Mini Apps SDK, автоматический профиль из `initData`, нативная кнопка «назад», haptic feedback, safe area и Telegram viewport;
- оформление заказа доступно только после автоматического входа через Telegram;
- системная типографика и плавающее меню в стиле Apple Liquid Glass.
